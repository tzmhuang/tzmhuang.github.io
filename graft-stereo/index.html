Leveraging Sparse LiDAR for RAFT-Stereo:
A Depth Pre-Fill Perspective

Jinsu Yoo, Sooyoung Jeon, Zanming Huang, Tai-Yu Pan, Wei-Lun Chao
The Ohio State University
arXiv

🚧 Note: This project page will be updated soon with more details and results.

With minimal architectural changes and an analysis of RAFT-Stereo's internal mechanism, we show that it can be effectively adapted for LiDAR-guided stereo.
